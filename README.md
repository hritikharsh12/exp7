Adaptive UI Using ListView and ImageView
This Android Studio project demonstrates an adaptive user interface using ListView and ImageView.

Technologies
Kotlin
XML
Android Studio
ListView
ImageView
Custom BaseAdapter
Features
Scrollable ListView
ImageView in every list item
Custom adapter
Responsive layout using match_parent and layout_weight
dp and sp dimensions
Item click Toast
Run
Open the project in Android Studio, allow Gradle synchronization, then run it on an emulator or Android device.
